# Rover Photogrammetry Viewer (RPV)

Stereo 360 panoramas of Mars rover stations, for a browser or a VR headset: https://ctate7163.github.io/RPV/

Created by Christian Tate at MSSS for research purposes, with the Rover Photogrammetry Pipeline: https://github.com/ctate7163/RPP

This repository is written by `mppp single-sites --upload`: do not edit `panos.json` or `panos/` by hand.
Images: NASA/JPL-Caltech (Navcam, Hazcam); NASA/JPL-Caltech/ASU/MSSS (Mastcam-Z). Viewer page: Apache-2.0 (RPP); three.js: MIT (`vendor/THREE_LICENSE`).
